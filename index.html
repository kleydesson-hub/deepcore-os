Sobre o Projeto

O DeepCore OS é um sistema integrado de IoT projetado para otimizar o consumo energético e manter o controle térmico estável em servidores de processamento intensivo. Utilizando lógica embarcada de automação, o hardware ativa o resfriamento ativo dinamicamente ao atingir limites críticos de temperatura, enviando métricas em tempo real via telemetria para a nuvem.

Tecnologias Utilizadas

ESP32 (Microcontrolador) DS18B20 (Sensor de Precisão) Protocolo MQTT WebSockets Seguros (WSS) HTML5 / CSS3 / JavaScript HiveMQ Broker
